# 01 – Overview

## What you get

- **Sign-in UI**: email + password by default. Social providers, email OTP and magic links are
  one switch away.
- **Account pages** at `/account` and `/account/profile`: name, avatar upload and crop, emails,
  phone number, linked accounts, password, API keys and account deletion.
- **Organizations** (optional): create and switch orgs, invite members, roles, logo, leave or
  delete. Every new user gets a "Personal Organization".
- **Admin dashboard** at `/admin` (optional): list and search users and orgs, ban, set roles,
  revoke sessions, impersonate.
- **Device authorization** (optional): the `/device` flow for CLIs and TVs.
- **Transactional emails** through Resend: verification, OTP, magic link, password reset,
  email change and invites.
- **Route protection** in `src/hooks.server.ts`.
- **SSR auth state**: the root layout preloads the user and org data, so the page doesn't flash
  while it loads.

None of the optional features are turned on yet. They're controlled by `src/convex/auth.constants.ts`
(see [05 – Configuration](./05-configuration.md)).

## Import aliases

`package.json` defines Node subpath imports. Use them instead of long relative paths:

```ts
import { api } from '#convex/_generated/api.js';
import Thing from '#lib/components/Thing.svelte';
```

`$lib` works too, as in any SvelteKit project.

## Upstream code

The `auth`, `users`, `organizations`, `admin` and `primitives` folders, and most of `src/convex/`,
came from the jsrepo registry. You own this code and can edit it. Re-running `jsrepo` to pull
upstream updates can overwrite your edits (and would bring back the Skeleton and Ark versions of the
UI files this template replaced), so put your own features in new folders where you can (for
example `src/lib/<feature>/` and `src/convex/<feature>/`).

## Open SvelteKit 3 migration items

`MIGRATION_TASKS.md` in the repo root lists files the SvelteKit 3 migration flagged for manual
review: `invalidateAll` to `refreshAll`, `goto` destinations, `json()` to `Response.json()` and
external redirects. Work through it, then delete it.
